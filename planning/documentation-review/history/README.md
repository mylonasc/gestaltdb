# Historical development reports

These files preserve development investigation and benchmark context removed
from published user guides. They are not current library documentation and are
not included in Sphinx. Their commands, links and capability statements describe
the original recorded revision, not necessarily the current library.

- `performance-development-report.rst`: storage comparisons, PyRex regression
  investigation/release validation and benchmark collection notes.
- `native-locator-development-report.rst`: native locator implementation phases,
  attribution diagnostics and adoption evaluation.
- `relational-execution-development-report.rst`: original structural contract,
  roadmap baseline register and reference-machine acceptance budgets.

Raw benchmark artifacts remain under `benchmarks/results/`. Current guidance is
in the corresponding `docs/` pages; authoring constraints are in
`planning/documentation-review/authoring-contract.md`.
