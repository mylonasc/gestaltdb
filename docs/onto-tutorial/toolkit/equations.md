# Equation conventions

Dollar math (``myst_enable_extensions = ["dollarmath"]``):

- Fixpoint: $$\mathrm{lfp}(T_P) = \bigcup_{n \ge 0} T_P^n(\emptyset)$$
- Subsumption: $$\frac{(x, C)}{(x, D)}\;(C \sqsubseteq D)$$
- Window hold: $$\mathrm{holds}(s,[t_1,t_2)) \iff \exists v: \mathrm{valid}(v) \supseteq [t_1,t_2)$$
